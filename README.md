# 🏆 Merdivenim Geldi - FPL Özel Lig İstatistik & Analiz Paneli

9 takımlı özel **"Merdivenim Geldi"** Fantasy Premier League ligi için geliştirilmiş modern, etkileşimli ve tek sayfalık istatistik takip paneli.

---

## 🌟 Özellikler

- 👑 **Zirve & Merdiven Özeti**: Güncel lider(ler), haftanın şampiyonu, en çok basamak yükselen menajer ve lig ortalamaları.
- 📋 **İnteraktif Puan Durumu**: Sıralama değişim okları (`▲ +2`, `▼ -1`, `▬`), form çizgisi (sparkline), liderle puan farkı.
- 🎢 **Sıralama Değişim Grafiği (Bump Chart)**: Haftalar boyunca 1'den 9'a pozisyon değişimleri.
- 📈 **Kümülatif Puan Yarışı**: Toplam puanların hafta hafta yarış çizgileri.
- 📊 **Haftalık Puan Dağılımı**: Her menajerin haftalık performansı vs Lig Ortalaması bar grafiği.
- 🥧 **Zirve Hakimiyeti**: Liderlik koltuğunda en çok hafta oturan menajerlerin grafiği.
- ⚔️ **1v1 Menajer Kapışması (Head-to-Head)**: İki arkadaşınızı seçip hafta hafta kim kimi geçmiş kıyaslama ekranı.
- 🏅 **Lig Rekorları & Şeref Kürsüsü**: Merdiven Kralı, Tek Hafta Rekoru, İstikrar Abidesi, vb.
- 👤 **Menajer Karnesi**: Menajere tıklandığında açılan detaylı analiz ve haftalık puan geçmişi.
- ➕ **Kolay Veri Girişi & Yedekleme**: 10 saniyede yeni hafta puanı ekleme, JSON yedek indirme/yükleme ve FPL Lig ID bağlantısı.

## 🚀 GitHub Pages ile Ücretsiz Yayına Alma (1 Dakika)

1. Bu projeyi GitHub hesabınıza push edin:
   ```bash
   git add .
   git commit -m "feat: initial release of Merdivenim Geldi dashboard"
   git branch -M main
   git remote add origin https://github.com/KULLANICI_ADINIZ/fpl-merdivenimgeldi.git
   git push -u origin main
   ```
2. GitHub'da deponuzun sayfasına gidin: **Settings (Ayarlar)** > **Pages** sekmesine tıklayın.
3. **Branch** kısmında `main` ve `/ (root)` seçip **Save** butonuna tıklayın.
4. 1 dakika içinde siteniz şu adreste canlıya geçer:
   > `https://KULLANICI_ADINIZ.github.io/fpl-merdivenimgeldi/`
